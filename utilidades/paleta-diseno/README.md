# Paleta SVG · Diseño

Genera muestras con sus códigos hexadecimales para abrir en navegador, Inkscape
o importar en un editor vectorial. Acepta de 2 a 12 colores `#RRGGBB`.
Crea un archivo nuevo; no sobrescribe. No requiere programas de diseño.

```powershell
.\script.ps1 -Destino paleta.svg -Colores '#2563EB','#0F172A','#F8FAFC'
py script.py paleta-python.svg "#2563EB" "#0F172A" "#F8FAFC"
```
