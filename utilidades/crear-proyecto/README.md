# Crear proyecto · Productividad

Crea `documentos`, `recursos`, `src`, `exportaciones` y un README con tareas.
El directorio padre debe existir. Rechaza cualquier destino existente.
Si falla a mitad, revisa la carpeta parcial antes de volver a intentarlo.

```powershell
.\script.ps1 -Destino "C:\Proyectos\Mi proyecto"
py script.py "C:\Proyectos\Mi proyecto Python"
.\ejecutar.cmd -Destino "C:\Proyectos\Otro proyecto"
```
