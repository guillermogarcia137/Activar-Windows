# Buscar duplicados · Productividad

Compara contenido con SHA-256, incluidos archivos ocultos y vacíos.
Devuelve JSON; nunca borra. Omite enlaces y junctions encontrados durante el
recorrido. Usa una carpeta estable: cambios concurrentes pueden invalidar el
informe. Un error de lectura aborta el informe. Los archivos grandes tardan.

```powershell
.\script.ps1 -Origen "C:\Datos"
py script.py "C:\Datos"
.\ejecutar.cmd -Origen "C:\Datos"
```
